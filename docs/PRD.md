# PRD: YouTube Channel Insight

## 목표
YouTube 채널 운영자가 자신의 공개 채널 데이터를 기반으로 다음에 만들 콘텐츠와 개선 우선순위를 결정하도록 돕는다.

## 사용자
- 1차 사용자: 자기 YouTube 채널을 성장시키고 싶은 채널 운영자.
- 사용자는 YouTube Studio나 기본 통계에서 숫자는 볼 수 있지만, 그 숫자를 다음 영상 기획으로 연결하는 데 어려움을 겪는다.
- 사용자는 긴 컨설팅 문서보다 바로 실행할 수 있는 다음 행동을 원한다.

## 해결할 문제
- 채널 데이터는 있지만 무엇이 잘 되고 있는지 해석하기 어렵다.
- 조회수가 높은 영상은 알지만 왜 잘 됐는지, 어떤 패턴을 반복해야 하는지 알기 어렵다.
- 다음 영상 주제, 포맷, 제목 방향을 감으로 정하는 경우가 많다.
- 분석 결과가 실행 체크리스트로 이어지지 않으면 실제 채널 운영 개선으로 연결되지 않는다.

## 핵심 가치
- 채널 URL 하나로 빠르게 진단한다.
- 최근 공개 영상 데이터에서 반복 가능한 성과 패턴을 찾는다.
- GPT 분석을 사용하되, 결과는 대시보드와 실행 체크리스트로 제공한다.
- 사용자가 분석을 읽고 끝내지 않고 다음 영상 제작 결정을 내리게 한다.

## 핵심 사용자 플로우
1. 사용자가 채널 URL 또는 `@handle`을 입력한다.
2. 앱이 URL 형식을 검증하고 지원하지 않는 형식은 즉시 안내한다.
3. 앱이 YouTube Data API로 채널 기본정보와 최근 공개 영상 최대 50개를 수집한다.
4. 앱이 수집된 데이터를 OpenAI Responses API로 분석한다.
5. 사용자는 한눈에 보는 진단, 성과 패턴 차트, 다음 영상 추천, 실행 체크리스트를 확인한다.
6. 사용자는 추천된 아이디어와 체크리스트를 바탕으로 다음 콘텐츠 제작 방향을 정한다.

## 핵심 기능
1. 채널 URL 입력 및 검증
   - 지원 형식: `youtube.com/@handle`, `@handle`, `youtube.com/channel/UC...`, `UC...`.
   - 미지원 형식: `/c/...`, `/user/...`, 개별 영상 URL, Shorts URL.
2. 채널 데이터 수집
   - 채널명, 설명, 썸네일, 구독자 수, 총 조회수, 총 영상 수.
   - 최근 공개 업로드 최대 50개.
   - 각 영상의 제목, 설명, 게시일, 조회수, 좋아요 수, 댓글 수, 썸네일, 길이.
3. AI 채널 분석
   - 전체 진단 점수.
   - 3줄 요약.
   - 강한 성과 신호.
   - 성장 병목.
   - 반복 가능한 콘텐츠 패턴.
   - 다음 영상 아이디어.
   - 실행 체크리스트.
4. 대시보드형 결과 화면
   - 점수 카드.
   - 상위 영상 랭킹.
   - 조회수/좋아요/댓글 성과 카드.
   - 최근 영상 성과 추이.
   - 업로드 리듬 차트.
   - 평균 대비 튄 영상 표시.
5. 다음 콘텐츠 추천
   - 다음 영상 아이디어 5개.
   - 각 아이디어는 제목 방향, 추천 포맷, 근거, 기대 효과, 난이도를 포함한다.
6. 실행 체크리스트
   - 우선순위 7개 이하.
   - 각 항목은 해야 할 일, 이유, 예상 효과, 우선순위를 포함한다.
7. 오류 및 빈 상태 가이드
   - 사용자가 실패 원인과 다음 조치를 이해할 수 있게 안내한다.
   - 분석 실패 시에도 수집된 데이터는 가능한 한 화면에 유지한다.

## 성공 기준
- 사용자가 채널 URL 입력 후 분석 결과까지 하나의 흐름으로 도달할 수 있다.
- 사용자는 결과 화면 첫 viewport에서 채널 상태와 이번 주 바로 할 일을 이해할 수 있다.
- 사용자는 다음 영상 아이디어를 최소 5개 받는다.
- 사용자는 실행 체크리스트를 보고 당장 수정할 운영 행동을 결정할 수 있다.
- API key 누락, 잘못된 URL, 채널 없음, 영상 없음, provider 실패가 명확한 메시지로 처리된다.

## MVP 제외 사항
- 사용자 로그인.
- DB 저장 및 분석 히스토리.
- YouTube OAuth.
- YouTube Analytics API.
- 비공개 영상/수익/시청 지속 시간/유입 경로 분석.
- 경쟁 채널 비교.
- 여러 채널 동시 분석.
- 예약 분석, 주기적 모니터링, 이메일 리포트.
- PDF, PPT, CSV 내보내기.
- 결제, 팀 권한, 워크스페이스.

## 기본 정책
- 분석 언어는 한국어다.
- 단일 채널만 분석한다.
- 최근 공개 영상은 최대 50개까지 분석한다.
- DB 없이 현재 화면 세션에서만 결과를 유지한다.
- 영상 수가 적어도 분석은 진행하되 confidence를 낮게 표시한다.
